Nesse projeto foi realizado:
- Análise exploratória sobre dados provenientes do The Movie Database (TMDB)
- Tratamento desses dados
- Aplicação de algoritmos de Machine Learning sobre esses dados (clusterização e classificação)
- Geração de gráficos para analise de resultados
- Criação de uma aplicação web Streamlit para a demonstração de resultados
